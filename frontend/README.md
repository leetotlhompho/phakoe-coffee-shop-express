# Phakoe's Coffee Shop Express - React frontend

React + Vite single-page app. It talks to the Express API in `../backend` using `fetch`.

```bash
cp .env.example .env      # VITE_API_URL=http://localhost:4000
npm install
npm run dev               # http://localhost:5173
```

Pages: Home, Menu (by category), Cart + checkout, Track order (name + order number, live status, printable slip),
Staff login, Staff/Admin dashboard. See the root README for the full system description and deployment steps.

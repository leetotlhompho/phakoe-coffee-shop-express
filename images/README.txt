Put your menu photos in this folder (JPG, PNG, WEBP, GIF or AVIF), for example:

    images/water.jpg

Then use the path in the "image" field of the menu data (backend/data/brewhaven-db.json
or backend/src/seedData.js):

    "image": "images/water.jpg"

Tips: use simple file names (letters, numbers, - and _), no spaces.
After adding a new photo, restart the website (npm run dev) so it is picked up.
